# Ud01_proyectBeaGarcia

Programa conversor de divisas (EUR a USD) y de temperatura (Celsius a Fahrenheit) en Python.

## Cómo ejecutarlo
```bash
python src/main.py

## Ejemplo
```text
EUR: 10
10.00 EUR = 10.80 USD
º C: 100
100.00 C = 212.00 F

## Estructura del proyecto
- `src/`: Contiene el código fuente del programa (main.py).
- `tests/`: Carpeta para pruebas unitarias del proyecto.
- `data/`: Carpeta para almacenamiento de archivos de datos.
- `docs/`: Carpeta para la documentación técnica del proyecto.
